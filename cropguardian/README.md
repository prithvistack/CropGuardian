# CropGuardian AI

AI-Powered Crop Intelligence & Automation Ecosystem — SIH prototype frontend for high-value tomato agriculture.

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173) in your browser.

## Build for production

```bash
npm run build
npm run preview
```

## Stack

- React 18 + Vite
- Tailwind CSS
- Recharts (data visualization)
- lucide-react (icons)

## Structure

- `src/App.jsx` — the entire application (dashboard, disease detection, storage monitoring, spraying history, disease library, reports, settings)
- `src/main.jsx` — React entry point
- `src/index.css` — Tailwind directives
